# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나

- 본인이 혼자 사용하는 개인용 페이지.
- 사용 환경은 Mac 컴퓨터의 Chrome 브라우저.

## 2. 무엇을 하려고

- 본 영화를 직접 추가해 티어별로 정리한다.
- 하나의 티어리스트를 사용하며, 처음에는 빈 목록으로 시작한다.
- 영화의 순서, 개인 별점, 글로 쓰는 감상평을 계속 수정하고 저장한다.
- TMDB(The Movie Database) 등 외부 영화 정보 검색 서비스를 연결하지 않는다.

## 3. 화면과 동작

### 전체 화면

- 검정·짙은 회색 바탕에 붉은 포인트를 사용하는 영화관 분위기.
- 한국어·영어를 선택하면 페이지 전체의 표시 언어를 전환한다.
- 기본 티어는 S/A/B/C/D/F이며, 이름과 색상만 수정할 수 있다. 티어 추가·삭제·순서 변경은 포함하지 않는다.
- 티어에 배치하기 전 영화를 두는 미분류 영역을 제공한다.

### 영화 추가·편집

- ‘영화 추가’ 버튼으로 수동 입력을 시작한다.
- 제목만 필수이며, 포스터 주소·개봉 연도·감독·장르·상영시간·줄거리는 선택 입력한다.
- 포스터는 이미지 주소를 붙여 넣는다. 이미지 업로드 기능은 포함하지 않는다.
- 포스터가 없으면 영화 제목이 적힌 기본 카드를 표시한다.
- 추가를 확정하면 미분류 영역에 배치한다.
- 추가한 영화의 정보는 상세 창에서 수정할 수 있다.
- 중복 추가를 방지한다.

### 영화 카드와 배치

- 제목과 개인 별점은 항상 표시한다. 연도는 마우스를 올리면 표시한다.
- 포스터 또는 기본 카드를 끌어 티어 사이로 이동하거나 같은 티어 안에서 순서를 바꾼다.
- 움직임은 빠르고 가볍게 표현한다.
- 드래그 중인 카드는 살짝 커지고 그림자가 생긴다.
- 주변 카드가 부드럽게 밀려 들어갈 자리를 만든다.
- 카드를 놓으면 튕김 없이 부드럽게 안착한다.
- 카드에 마우스를 올리면 삭제 버튼이 나타나며, 삭제 후 되돌리기를 제공한다.

### 상세 창

- 카드를 클릭하면 화면 중앙에 약 60% 크기의 창을 연다.
- 세로 구분선을 기준으로 왼쪽에는 영화 정보, 오른쪽에는 개인 별점과 감상평을 표시한다.
- 배경은 어둡게 하고 살짝 흐리게 처리한다.
- 바깥을 클릭하거나 Esc 키를 누르면 닫힌다.
- 별점은 5점 만점, 0.5점 단위이며 별 이미지와 숫자로 함께 표시한다.
- 별의 왼쪽 절반과 오른쪽 절반을 클릭해 반 점 단위로 선택한다.
- 글로 쓰는 감상평을 입력하고 수정할 수 있다.

### 저장

- 사용자가 처음에 저장 대상 HTML(HyperText Markup Language) 파일을 연결하고 파일 쓰기 권한을 허용한다.
- 영화 추가·편집·이동, 별점·감상평 및 설정 변경을 연결한 HTML 파일 자체에 자동 저장한다.
- 파일을 다시 열면 저장한 내용을 복원한다.
- 별도 백업 다운로드 버튼은 제공하지 않는다.
- 실제 파일 자동 저장과 재연결 동작은 구현 시 Mac Chrome에서 검증해야 한다. 재접속 시 권한 재확인이 필요할 수 있다.

### 아직 정하지 않은 부분

- 중앙 상세 창의 ‘60%’가 화면 너비 기준인지, 너비·높이 모두인지.
- 초기 티어별 색상, 글꼴, 포스터 크기와 구체적인 화면 배치.
- 한국어·영어 중 최초 표시 언어와 직접 입력한 영화 정보의 언어별 관리 여부. 자동 번역은 합의하지 않았다.
- 수동 입력 영화의 중복 판정 기준. 같은 제목의 다른 영화 구분 방법이 필요하다.
- 별점 미입력 상태의 표시와 별점을 지우는 방법.
- 포스터 주소가 유효하지 않거나 이미지 표시가 차단될 때의 처리.
- 삭제 되돌리기의 유지 시간과 적용 범위.
- 감상평 입력 중 자동 저장 시점, 저장 상태 표시와 저장 실패 시 처리.
- 외부 검색을 제외한 뒤 수동 추가에 별도 미리보기 단계를 둘지 여부.

## 4. 필요한 자료

- 사용자가 직접 입력할 영화 제목.
- 원하는 경우 포스터 이미지 주소와 개봉 연도·감독·장르·상영시간·줄거리.
- 사용자가 작성할 개인 별점과 감상평.
- 자동 저장 대상으로 연결할 HTML 파일과 파일 쓰기 권한.
- 초기 영화 목록은 필요하지 않다. 빈 상태로 시작한다.
- 외부 영화 정보 서비스의 계정이나 인증 키는 필요하지 않다.
- 참고 이미지·로고 등 별도의 디자인 자료는 정하지 않았다.

## 5. 완성 기준

- 제목만 입력해 영화를 추가할 수 있고, 추가한 영화가 미분류 영역에 나타난다.
- 이미지 주소로 포스터가 표시되며, 포스터 없이도 제목 카드로 사용할 수 있다.
- 영화 정보를 수정하고 티어 사이 이동 및 같은 티어 내 순서 변경이 가능하다.
- 티어 이름과 색상을 수정할 수 있다.
- 상세 창이 중앙에 열리고, 영화 정보와 개인 기록이 좌우로 구분된다.
- 0.5점 단위 별점과 글로 쓰는 감상평을 작성·수정할 수 있다.
- 합의한 카드 표시, 애니메이션, 창 닫기, 삭제·되돌리기가 작동한다.
- 합의할 중복 판정 기준에 따라 중복 추가를 방지한다.
- 한국어·영어 전환이 페이지 전체에 적용된다.
- 변경 내용이 연결한 HTML 파일 자체에 자동 저장된다.
- 파일을 닫고 다시 열었을 때 영화·티어 배치·순서·별점·감상평·언어·티어 이름과 색상이 복원된다.
- 아직 정하지 않은 세부 사항은 임의로 확정하지 않고 제작 전에 결정한다.
